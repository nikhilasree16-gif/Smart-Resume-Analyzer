# Smart Resume Analyzer

An AI-powered Resume Analyzer built using Python and Streamlit.

## Features
- Upload Resume PDF
- Extract Resume Content
- Analyze Skills
- Suggest Career Roles
- Simple and Interactive UI

## Tech Stack
- Python
- Streamlit
- Pandas
- PDFPlumber
- Scikit-learn
